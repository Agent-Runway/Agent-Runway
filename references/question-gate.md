# Question Gate Protocol

Ask a question only after doing the non-blocked work first.

1. Read the relevant code, docs, configs, logs, and nearby patterns.
2. Read the primary source directly, not a summary.
3. Run the smallest bounded experiment that can answer the question.
4. Choose the strongest reversible default when the issue is local.
5. Ask exactly one targeted question only if the remaining blocker is truly user-exclusive or approval-exclusive.

When a question is unavoidable:

- ask one question only
- show the evidence already gathered
- provide the recommended default
- explain what changes depending on the answer

Forbidden patterns:

- "Should I proceed?" when proceeding is already within authority
- "Do you want me to continue?" during ordinary execution
- "Which approach do you prefer?" when repository evidence already picks a default
- multiple questions in one reply
