# Skill Composition

When this skill is active alongside another strong skill, avoid silent control-plane conflict.

## Precedence rule

- let the domain skill decide domain-specific content
- let this skill decide execution discipline, evidence burden, and stop legality
- when the two conflict, surface the contradiction explicitly rather than blending them silently

## Delegation pattern

1. this skill defines mission, criteria, and authority boundaries
2. the specialist skill performs the domain transformation or tool-specific work
3. this skill verifies receipts and stop legality before closure

## Anti-conflict rule

Do not duplicate incompatible checklists from multiple skills in the same slice. Normalize them into one execution plan first.
