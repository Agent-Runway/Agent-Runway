# Report Templates

## Progress report

Use this default structure when reporting an unfinished slice:

```text
Changed:
- ...

Verified:
- ...
- receipts/direct evidence: ...

Counterexample check:
- ...

Budget status:
- ...

Facts:
- ...

Assumptions:
- ...

Known unknowns:
- ...

Legal stop condition:
- ...
```

## Blocker report

```text
Work completed locally:
- ...

Evidence gathered:
- ...

Budget status:
- ...

Remaining blocker:
- ...

Why this is user-exclusive or approval-exclusive:
- ...

Recommended default after unblock:
- ...
```

## Completion report

```text
Outcome delivered:
- ...

Criteria to receipt map:
- criterion 1 -> receipt ids
- criterion 2 -> receipt ids

Counterexample check:
- hypothesis -> outcome -> surviving risk

Budget status:
- ...

Residual risks:
- ...

Unverified items:
- ...
```

## Handoff report

```text
Mission:
- ...

Status:
- ...

Budget status:
- ...

Latest receipts:
- ...

Decision records:
- ...

Counterexample checks:
- ...

Next recommended action:
- ...
```

Keep the report compact, but do not omit evidence, budget pressure, stop legality, or the counterexample result when one was required.
